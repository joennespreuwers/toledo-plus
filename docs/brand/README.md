# Toledo+ brandguide v1.0

- `brandguide.pdf` — de gids (logo, vrije ruimte, formaten, kleuren, type)
- `logo/` — SVG-masters: icoon met tegel (primair), glyph (transparant), mono wit/ink
- `png/` — icoon 16–1024 px, glyph 128/512 px
- `extension/` — `icons/icon16|32|48|128.png` + `manifest-icons.json` om in je manifest te plakken
- `tokens/` — kleuren als CSS-variabelen en JSON
